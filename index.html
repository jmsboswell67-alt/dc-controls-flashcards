⚙ Type-Mode Settings (Ollama)

First-time setup on Windows:
  1. Stop Ollama (right-click the tray icon → Quit Ollama).
  2. Open System Properties → Environment Variables and add a new user variable: OLLAMA_ORIGINS = * (this lets the browser talk to Ollama from a local HTML file). Restart Ollama after.
  3. In PowerShell, pull a model if you haven't: ollama pull llama3.1
  4. Click Test connection below.

Recommended models for grading:
llama3.1 (8B, balanced, default) · qwen2.5 (strong reasoning) · llama3.2:3b (fast, smaller, less accurate)
